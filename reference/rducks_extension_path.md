# Locate the built Rducks DuckDB extension

Locate the built Rducks DuckDB extension

## Usage

``` r
rducks_extension_path()
```

## Value

Character scalar path to `rducks.duckdb_extension`.

## Examples

``` r
rducks_extension_path()
#> [1] "/home/runner/work/_temp/Library/Rducks/rducks_extension/build/rducks.duckdb_extension"
```
